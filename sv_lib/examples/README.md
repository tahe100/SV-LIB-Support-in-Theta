# Examples for SV-LIB

This directory contains example SV-LIB files that demonstrate various features of the format.
These examples can be used
for testing, learning, and reference when creating your own SV-LIB files.

## Naming Convention

We distinguish between programs and witnesses by using different file name suffixes:

- Files ending with `.svlib` are SV-LIB program files.
- Files ending with `.witness.svlib` are SV-LIB witness files.
